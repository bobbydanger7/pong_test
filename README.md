# Simple Pong

A lightweight browser-based Pong game built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static file server.

## Controls

- Player 1: `W` / `S`
- Player 2: `↑` / `↓`
- Pause / resume: `Space`
- Restart: on-screen **Restart** button
